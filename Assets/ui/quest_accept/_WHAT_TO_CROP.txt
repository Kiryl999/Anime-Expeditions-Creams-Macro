quest_accept -- REFERENCE IMAGE STILL MISSING

Put a crop named exactly "quest_accept.png" in THIS folder.

What to crop:
  The button that ACCEPTS the quest in the NPC's dialog. Crop the button
  including its label text -- the label is what separates it from the
  redeem buttons below, so a crop of the bare frame is not enough.

Where/how:
  Crimson Shore > quest NPC > E, with no quest currently running.

Used by:
  Starting a cycle -- and, just as importantly, RECOGNIZING that no quest
  is running: if this button is the one in the dialog, the macro knows a
  previous cycle did not leave anything half finished.

Easiest way: Settings > General > Image Manager > "UI Buttons" tab > Capture
Roblox, drag a box around it, type the name "quest_accept", Save Crop -- that writes
the file here and no restart is needed. A hand-made PNG dropped in here works
too; use Settings > "Reload Vision Images" afterwards so the cache picks it up.

Crop TIGHTLY, with as little surrounding background as possible. More crops of
the SAME thing can be added here under any other .png name (e.g.
"quest_accept_alt2.png") -- all of them are tried before the search gives up, which
is how you fix an element that renders slightly differently on your setup.

Delete this .txt once the .png is in place; it only exists so the empty folder
survives in git. It is ignored by the image search (only .png is read).

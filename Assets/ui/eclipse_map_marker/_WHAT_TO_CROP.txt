eclipse_map_marker -- REFERENCE IMAGE STILL MISSING

Put a crop named exactly "eclipse_map_marker.png" in THIS folder.

What to crop:
  The Eclipse marker that sits ABOVE a story map's name in the Play >
  Story carousel. Crop the marker itself -- NOT the map name under it,
  and not the card art.

  It has to be the part that is identical no matter WHICH map carries the
  event, because that is the whole point: the macro finds the marker
  first and reads which map it is sitting on second.

Where/how:
  Lobby > Play > Story, after accepting the quest. Exactly one map in
  the carousel carries the marker.

Used by:
  Finding which story map is running the Eclipse event this cycle.

Easiest way: Settings > General > Image Manager > "UI Buttons" tab > Capture
Roblox, drag a box around it, type the name
"eclipse_map_marker", Save Crop -- that writes the file here and no restart is needed. A hand-made PNG dropped in here works
too; use Settings > "Reload Vision Images" afterwards so the cache picks it up.

Crop TIGHTLY, with as little surrounding background as possible. More crops
of the SAME thing can be added here under any other .png name (e.g.
"eclipse_map_marker_alt2.png") -- all of them are tried before the
search gives up, which is how you fix an element that renders slightly
differently on your setup.

Delete this .txt once the .png is in place; it only exists so the empty folder
survives in git. It is ignored by the image search (only .png is read).

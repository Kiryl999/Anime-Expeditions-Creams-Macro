world_boss_enter_encounter

The "Enter Encounter" button on the World Boss screen. The macro clicks it
after the Ancient One entry (see world_boss_ancient_one), then goes on to
Select Stage and Start like any stage.

One crop ships with the macro. If it does not match on your setup, add
another: drop one or more PNG crops here (any filename ending .png), or save
one via Settings > General > Image Manager under this exact name. Multiple
files are treated as interchangeable variants of this image and all tried
when matching. Capture crops at the reference window size (1152x756). See
Assets/ui/README.txt.

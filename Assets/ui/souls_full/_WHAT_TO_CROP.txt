souls_full -- REFERENCE IMAGE STILL MISSING

Put a crop named exactly "souls_full.png" in THIS folder.

What to crop:
  Whatever marks the soul item in the Victory screen's loot row as
  FULL/capped at 150 -- the "you cannot pick any more up" state.

  Crop the part that is different from a normal soul drop. If the only
  difference is a number (a "150" badge, or a greyed-out cell), crop that
  badge/cell tightly: it is being matched as an image, not read as text,
  so it has to look meaningfully different from the uncapped state or the
  macro cannot tell the two apart.

Where/how:
  Finish an Eclipse run while already holding 150 souls -- the loot row
  on the Victory screen shows the capped state.

Used by:
  The stop condition for the farm loop: while this is absent the macro
  presses Retry and runs the event again; the moment it matches, the
  cycle moves on to redeeming at the NPC.

Easiest way: Settings > General > Image Manager > "UI Buttons" tab > Capture
Roblox, drag a box around it, type the name
"souls_full", Save Crop -- that writes the file here and no restart is needed. A hand-made PNG dropped in here works
too; use Settings > "Reload Vision Images" afterwards so the cache picks it up.

Crop TIGHTLY, with as little surrounding background as possible. More crops
of the SAME thing can be added here under any other .png name (e.g.
"souls_full_alt2.png") -- all of them are tried before the
search gives up, which is how you fix an element that renders slightly
differently on your setup.

Delete this .txt once the .png is in place; it only exists so the empty folder
survives in git. It is ignored by the image search (only .png is read).
